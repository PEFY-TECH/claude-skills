# PEFY-GG UI/UX — Codex repository discovery

This directory is the **Codex / Agent Skills discovery adapter** for the PEFY-TECH source repository. Before performing a design task, read the **complete canonical rules** at `pefy-uiux-governed-design/SKILL.md` in the repository root.

- Discover product audience, journeys, constraints, locales, device limitations, and formal risk/regulatory requirements.
- Apply WCAG 2.2 AA as the baseline target where applicable; never claim certification without tested evidence.
- Only invoke a version-pinned, approved UI UX Pro Max engine in the actual active runtime. If missing, say it is unavailable and do not pretend its datasets were executed.
- Guard privacy and security; never transmit classified/customer information to unapproved tooling.
- Do not conflate the presence of these source files with activation in ChatGPT or external Codex installations.
- Maintain design tokens, implementation quality gates, reviews and rollback documentation as prescribed in the canonical skill.
